# 체험단 승인 일정 관리 웹사이트 (Node.js)

네이버 블로거 1인 사용을 가정한 체험단 관리 페이지입니다.
승인된 체험단을 등록하고 방문마감일/리뷰 마감기한을 기준으로 마감 임박 일정을 확인할 수 있습니다.

## 주요 기능
- **메뉴 분리**
  - 체험단 등록 메뉴
  - 체험단 목록 메뉴
- **체험단 사이트 관리 분리**
  - 사이트를 직접 추가/삭제하고 등록 폼에서 선택
- **체험단 유형 관리 분리**
  - 방문형/배송형/구매형 외 유형도 직접 추가/삭제
- 방문마감일 및 리뷰 마감기한 기반 상태 표시
- 브라우저 `localStorage` 기반 저장 (개인 단독 사용)

## 시작하기

### 1) 요구사항
- Node.js 18 이상

### 2) 실행
```bash
npm run start
```

브라우저에서 아래 주소를 엽니다.
- http://localhost:3000
