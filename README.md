# 체험단 일정관리 웹사이트 (Node.js)

네이버 블로거 1인 사용을 가정한 체험단 관리 페이지입니다.
승인된 체험단을 등록하고 방문예약일/리뷰 마감기한을 기준으로 마감 임박 일정을 확인할 수 있습니다.

## 핵심 변경점
- 데이터 저장 위치를 브라우저가 아닌 **서버 파일**로 분리
  - `data/experiences.json` 파일에 저장
  - 코드 업데이트 후에도 데이터 유지
- 헬로키티 이미지를 제거하고 텍스트 중심 UI로 정리

## 주요 기능
- **메뉴 분리**
  - `🐱 체험단 등록 메뉴`
  - `🐱 체험단 목록 메뉴`
- **체험단 사이트 관리 분리**
  - 사이트를 직접 추가/삭제하고 등록 폼에서 선택
- **체험단 유형 관리 분리**
  - 기본 유형 외에도 직접 추가/삭제
- 방문예약일/리뷰마감기한에 요일 함께 표시
- 방문예약일시(날짜+시간) 기록 지원
- 체험단 유형이 `배송형`일 때
  - 방문예약일시 라벨이 `배송완료일`로 변경
  - 배송여부(O/X) 입력 항목 표시
- 체험단 유형이 `방문형`일 때 (목록 수정 모달)
  - 방문시간 수정 가능
  - 추가사용금액 입력 가능
  - 추가미션 메모 가능 (예: 네이버영수증리뷰/네이버클립)
- 체험단 상세 항목 추가
  - 방문지역
  - 제공받은금액
  - 페이백금액(체험단 유형이 `페이백`일 때만 표시)
- 체험단 목록 메뉴에서 등록 데이터 수정/삭제 가능
  - 삭제 시 모달 확인 팝업 제공
  - 수정 시 등록 메뉴 이동 없이 목록 화면 내 모달에서 바로 수정

## 시작하기

### 1) 요구사항
- Node.js 18 이상

### 2) 실행
```bash
npm run start
```

브라우저에서 아래 주소를 엽니다.
- http://localhost:3000

- `PUT /api/data`: 데이터 저장
