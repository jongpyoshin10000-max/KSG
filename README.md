# 슬기의 바이브코딩 웹사이트 (Node.js)

간단한 Node.js 정적 웹 서버 프로젝트입니다.

## 시작하기

### 1) 요구사항
- Node.js 18 이상

### 2) 설치
```bash
npm install
```

### 3) 실행
```bash
npm run start
```

브라우저에서 아래 주소를 열어 확인합니다.
- http://localhost:3000

## 프로젝트 구조

```text
.
├── app.js
├── package.json
├── public/
│   └── index.html
└── README.md
```

## 스크립트
- `npm run start`: 서버 실행
- `npm run dev`: 개발 모드(동일 명령)
