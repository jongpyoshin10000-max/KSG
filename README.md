# 체험단 승인 일정 관리 웹사이트 (Node.js)

네이버 블로거 1인 사용을 가정한 체험단 관리 페이지입니다.
승인된 체험단을 직접 입력하고, 체험기간/리뷰 마감기한을 기준으로 마감 임박 항목을 관리할 수 있습니다.

## 주요 기능
- 승인된 체험단 등록 (방문형/배송형/구매형)
- 체험기간 마감일 / 리뷰 마감기한 저장
- 마감 임박(3일 이내) 건수 요약
- 승인 목록 조회 및 삭제
- 브라우저 `localStorage` 기반 저장 (개인 단독 사용)

## 시작하기

### 1) 요구사항
- Node.js 18 이상

### 2) 실행
```bash
npm run start
```

브라우저에서 아래 주소를 엽니다.
- http://localhost:3000
